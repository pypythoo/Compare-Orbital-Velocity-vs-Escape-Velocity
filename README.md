# Compare-Orbital-Velocity-vs-Escape-Velocity
This project compares orbital velocity and escape velocity and explores how they differ for each planet in our solar system.
It is based on gravitational physics and Newtonian mechanics.
The objective of this mini research project is to understand why escape velocity is always greater than orbital velocity, and how both depend on a planet’s physical properties.
